# Tashi Phagmo | Personal webpage

This repository contains the source for my personal website, covering my background, research interests, projects, CV, and contact information.

The custom design combines a Swiss-inspired layout with Tibetan typography and decorative elements. The Projects section includes an interactive, browser-based terminal for exploring project summaries and method notes using commands such as `ls`, `cd`, and `cat`.

## Technology

Built with **Jekyll (Ruby)**, with content written in **Markdown** and a custom interface using **HTML**, **CSS**, and **JavaScript**. The site is designed for deployment on **GitHub Pages**.

## Repository structure

| Directory | Contents |
| --- | --- |
| `_sections/` | About, Research, Projects, CV, and Contact content |
| `_projects/` | Individual project summaries and terminal notes |
| `_data/` | Profile information and social links |
| `_layouts/` | Shared page layout |
| `_includes/` | Reusable components, including navigation and the terminal |
| `assets/` | Stylesheets, scripts, images, icons, and local fonts |
